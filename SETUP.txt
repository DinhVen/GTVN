================================================================================
        HƯỚNG DẪN CÀI ĐẶT VÀ CHẠY PROJECT - TRAFFIC SIGN RECOGNITION
================================================================================

📋 YÊU CẦU HỆ THỐNG:
--------------------
- Python 3.8+ (khuyến nghị Python 3.9 hoặc 3.10)
- Node.js 16+ và npm
- Git


📥 BƯỚC 1: CLONE PROJECT TỪ GIT
--------------------------------
git clone <repository-url>
cd <project-folder>


🔧 BƯỚC 2: CÀI ĐẶT BACKEND (Python FastAPI)
--------------------------------------------
1. Di chuyển vào thư mục backend:
   cd backend

2. (Khuyến nghị) Tạo môi trường ảo Python:
   python -m venv venv
   
   # Kích hoạt môi trường ảo:
   # Trên Windows:
   venv\Scripts\activate
   # Trên Linux/Mac:
   source venv/bin/activate

3. Cài đặt các thư viện cần thiết:
   pip install -r requirements.txt

4. Quay lại thư mục gốc:
   cd ..


🎨 BƯỚC 3: CÀI ĐẶT FRONTEND (React + Vite)
-------------------------------------------
1. Di chuyển vào thư mục frontend:
   cd frontend

2. Cài đặt các dependencies:
   npm install

3. Quay lại thư mục gốc:
   cd ..


📊 BƯỚC 4: CHUẨN BỊ DỮ LIỆU (NẾU CẦN)
--------------------------------------
⚠️ LƯU Ý: Backend cần có sẵn các file sau trong thư mục data/:
   - faiss_index.faiss
   - metadata.csv
   - image_embeddings.npy

Nếu chưa có, chạy script rebuild FAISS index:
   cd backend
   python rebuild_faiss.py
   cd ..


🚀 BƯỚC 5: CHẠY ỨNG DỤNG
-------------------------

A. CHẠY BACKEND:
   1. Mở terminal/cmd thứ nhất
   2. Di chuyển vào thư mục backend:
      cd backend
   
   3. (Nếu dùng venv) Kích hoạt môi trường ảo:
      # Windows:
      venv\Scripts\activate
      # Linux/Mac:
      source venv/bin/activate
   
   4. Chạy server:
      python main.py
      
      HOẶC:
      uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   
   ✅ Backend sẽ chạy tại: http://localhost:8000
   ✅ API docs tại: http://localhost:8000/docs


B. CHẠY FRONTEND:
   1. Mở terminal/cmd thứ hai (giữ terminal backend đang chạy)
   2. Di chuyển vào thư mục frontend:
      cd frontend
   
   3. Chạy development server:
      npm run dev
   
   ✅ Frontend sẽ chạy tại: http://localhost:5173
      (hoặc port khác nếu 5173 đã được sử dụng)


🌐 BƯỚC 6: SỬ DỤNG ỨNG DỤNG
----------------------------
1. Mở trình duyệt và truy cập: http://localhost:5173
2. Upload ảnh biển báo giao thông
3. Xem kết quả nhận diện


🛠️ CÁC LỆNH HỮU ÍCH KHÁC
--------------------------

Backend:
--------
- Chạy với auto-reload (tự động restart khi code thay đổi):
  uvicorn main:app --reload

- Chạy trên port khác:
  uvicorn main:app --port 8080

Frontend:
---------
- Build cho production:
  npm run build

- Preview bản build:
  npm run preview

- Chạy linter:
  npm run lint


❌ KHẮC PHỤC SỰ CỐ THƯỜNG GẶP
------------------------------

1. Lỗi "FAISS index not found":
   → Chạy: python backend/rebuild_faiss.py

2. Lỗi "Module not found" (Python):
   → Kiểm tra đã kích hoạt venv và cài đặt requirements.txt

3. Lỗi "command not found: npm":
   → Cài đặt Node.js từ https://nodejs.org/

4. Port 8000 hoặc 5173 đã được sử dụng:
   → Đổi port hoặc tắt ứng dụng đang dùng port đó

5. CORS error khi gọi API:
   → Kiểm tra backend đang chạy và frontend đang gọi đúng URL


📞 HỖ TRỢ
----------
Nếu gặp vấn đề, kiểm tra:
- Backend logs trong terminal đang chạy backend
- Frontend logs trong terminal đang chạy frontend
- Browser console (F12) để xem lỗi JavaScript
